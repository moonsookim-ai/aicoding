# 강사용 안내

『클로드 완전정복 100단계』로 수업을 여는 분을 위한 부별 안내다. 파일마다 이 부의 목표, 단계별 수업 시간표,
꼭 보여 줄 시연, 과제 채점 기준(우수·통과·보완), 슬라이드 뼈대, 자주 나오는 질문이 들어 있다.

(웹의 각 부 쪽에서 PDF로 내려받는다)과 책 부록의 「짧게 도는 코스」를 함께 보고 줄인다.
