# 강사용 안내

『클로드·GPT 완전정복 100단계』(5편 11부 100단계)로 수업을 여는 분을 위한 부별 안내입니다. 파일마다 이 부의 목표,
단계별 수업 시간표, 꼭 보여 줄 시연, 과제 채점 기준(우수·통과·보완), 슬라이드 뼈대, 자주 나오는 질문이 들어 있습니다.
원고에 「ChatGPT에서는」·「Codex에서는」 상자가 있는 부는 ChatGPT·Codex를 쓰는 수강생을 위한 시연이나 질문도 함께 넣었습니다.

시간표는 각 단계의 「걸리는 시간」에 도입과 정리를 더해 짰습니다. 편 발표는 따로 줄을 두었습니다(제1편은 제2부 마치는 글,
제2편은 제4부 39단계, 제4편은 제8부 마치는 글). 수업 길이가 짧으면 부별 한 장 요약(웹의 각 부 쪽에서 PDF로 내려받는다)과
책 부록의 「짧게 도는 코스」를 함께 보고 줄입니다.
