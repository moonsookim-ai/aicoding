## 8. 30·60·90일

| 기간 | 할 일 | 끝났다고 볼 기준 | 결과(했다 / 막혔다 / 이유) |
|---|---|---|---|
| 1~30일 | As-is를 재서 기준값을 구한다. 암묵지를 적어 지침·스킬을 만들고, To-be를 손으로 한 번 이상 끝까지 돌린다 | 기준값이 적혀 있고, 지침을 적어도 한 번 고쳤다 | |
| 31~60일 | To-be로 일한다. 필요한 곳만 연결자·자동화로 잇고, 지표를 매주 적는다. 틀린 곳이 나올 때마다 지침과 스킬을 고친다 | 지표가 네 주 이상 쌓였고, 확인 지점을 건너뛴 일이 없다 | |
| 61~90일 | 기준값과 비교해 판정한다. 넘기는 부서와 양식을 맞추고, 확산 여부를 정한다 | 유지·수정·중단 가운데 하나로 결론을 냈다 | |

## 9. 확산 조건

옆 부서로 넓히기 전에 모두 갖춘다.

- [ ] 지표가 기준값보다 나아졌고, 빨라진 만큼 정확도가 떨어지지 않았다
- [ ] 확인 지점을 건너뛴 일이 없었다
- [ ] 담당자가 휴가를 가도 흐름이 돌 만큼 지침과 스킬이 글로 남아 있다
- [ ] 받는 부서가 넘겨받을 양식에 동의했다
