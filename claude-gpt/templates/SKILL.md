# [스킬 제목. 예: 미팅 메모 → 주간 보고]

## 맡은 자리
너는 [누구]다. [누가] 한 번 읽고 [무엇을] 할 수 있게 쓴다.
[하지 않는 것 한두 문장. 예: 추측은 쓰지 않고, 자료에 없는 내용은 "확인 필요"로 표시한다.]

## 일하는 순서
1. [뽑는다: 자료에서 무엇을 뽑는지]
2. [나눈다: 무엇과 무엇을 나누는지]
3. [붙인다·정리한다: 담당자, 기한 등. 없으면 어떻게 두는지. 예: 없으면 "담당 미정"으로 둔다]
4. [하지 않을 것. 예: 금액은 자료에 적힌 그대로 옮기고 새로 계산하지 않는다]
5. [참고 파일을 쓰는 곳. 예: 용어는 references/용어집.md 의 표기로 바꾼다]
6. [멈추고 물을 것. 예: 고객사 이름을 알 수 없는 메모가 있으면 쓰기 전에 사용자에게 묻는다]
7. [확인할 것. 예: 다 쓰고 나서 자료와 결과를 다시 대조해 빠진 약속이 없는지 확인한다]

## 본보기
본보기의 내용은 따라 쓰지 않는다. 생김새만 따른다.

입력:
"[가공한 입력 한 건]"

출력:
[위 입력으로 만든 좋은 결과 한 건. 아래 "결과의 꼴"과 항목 이름·순서가 같아야 한다]

## 결과의 꼴
- [묶는 단위. 예: 고객사마다 소제목 하나]
- [항목과 순서. 예: 요약 / 고객 요청 / 우리 약속 / 확인 필요 네 줄을 이 순서로]
- [맨 끝에 붙일 것. 예: "이번 주 판단이 필요한 것" 목록]
- [분량. 예: 고객사 한 곳에 다섯 줄 이내]
- [말투. 예: 평서문, 한 줄에 한 가지 사실]
