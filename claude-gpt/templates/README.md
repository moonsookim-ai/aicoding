# 채워 쓰는 양식

『클로드 완전정복 100단계』 본문에 나오는 양식을 파일로 옮겼다. 복사해서 `[ ]`와 `____` 안을 우리 팀 내용으로
채우면 된다. 파일 맨 위의 `<!-- -->` 주석은 쓰는 법 안내이니, 다 채운 뒤 지워도 된다.

예시로 적힌 내용은 모두 가상 회사 누리상사를 두고 꾸며 낸 것이다. 연습할 때 쓸 가공 자료는
[`../samples/`](../samples/)에 있다.

## 쓰는 순서

1. 해당 단계를 먼저 읽는다. 양식은 본문의 요약이라 이유와 사례는 본문에 있다.
2. 양식을 복사해 내 작업 폴더에 둔다. `CLAUDE_예시.md`는 이름을 `CLAUDE.md`로 바꿔 작업 폴더 맨 위에, `SKILL.md`는
   `.claude/skills/이름/SKILL.md`처럼 스킬 폴더 안에 둔다. 폴더 위치는 버전에 따라 다를 수 있으니 공식 문서를 확인한다.
3. 모르는 칸은 지어내지 않는다. 비워 두고 누가 언제까지 채울지 적는다.
4. 실제 고객 이름, 금액, 개인정보, 인증키는 어떤 양식에도 적지 않는다.

## 함께 지킬 원칙

- 메일 발송, 결제, 삭제, 제출, 계약 확정처럼 밖으로 나가거나 되돌릴 수 없는 일은 사람이 마지막에 확인한다.
- 요금과 한도는 양식에 적어 두지 않는다. 쓸 때마다 공식 요금 안내를 확인한다.
- 화면의 메뉴 이름과 위치는 자주 바뀐다. 책·양식과 공식 문서가 다르면 공식 문서를 따른다.
