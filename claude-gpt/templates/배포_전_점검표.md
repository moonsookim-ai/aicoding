- 도구 이름: [          ]   저장소: [          ]   배포 서비스: [Vercel / Cloudflare Pages / 회사가 정한 서비스]
- 점검한 사람: [이름]   점검일: [YYYY-MM-DD]

## 1. 올리기 전에

- [ ] 회사 업무용 도구를 올려도 되는 요금제·계정인지 확인했다(예: Vercel Hobby는 개인·비상업 용도). 확인한 사람: [          ]
- [ ] 배포 서비스에 허용한 저장소가 이 도구의 저장소 하나뿐이다
- [ ] 저장소 맨 위에 index.html이 있다(HTML 파일 하나로 된 도구라면)
- [ ] 파일 이름의 대소문자가 코드 속 이름과 같다(`Logo.png`와 `logo.png`는 다른 파일이다)

## 2. 공개 범위 거르기

주소를 아는 누구나 열 수 있다고 보고 거른다.

| 도구에 들어간 것 | 공개 주소에 올려도 되나 | 확인 |
|---|---|---|
| 회사 소개, 공개된 제품 정보 | 된다 | [ ] |
| 가공한 연습 자료, 업종·지역 같은 범주 | 대체로 된다. 실제 이름이 섞이지 않았는지 본다 | [ ] |
| 직원 이름, 내부 숫자 | 조심한다. 접근 제한 기능이 없으면 빼고 배포한다 | [ ] |
| 고객 정보, 인증키 | 안 된다. 화면과 저장소 어디에도 두지 않는다 | [ ] |

- [ ] 코드·설정 파일·입력란 예시 문구 어디에도 실제 회사 이름, 사람 이름, 연락처가 없다
- [ ] 접근을 제한해야 하는 도구라면 서비스와 요금제의 접근 제한 방법을 확인했다

## 3. 인증키

- [ ] 저장소와 화면 코드 어디에도 인증키 값이 없다
- [ ] 키는 환경변수로만 읽는다. 노트북용 값 파일(`.env.local` 등)은 저장소에 올라가지 않는다
- [ ] 저장소에는 이름만 적힌 예시 파일(`.env.example`)이 있다
- [ ] 키가 필요한 요청은 서버 쪽 함수가 보내고, 키가 브라우저로 가지 않는다
- [ ] 배포 서비스의 환경변수 항목에 값을 넣었고, 넣은 뒤에 다시 배포했다
- [ ] 예전에 키를 저장소나 화면 코드에 적은 적이 있다면, 그 키는 발급한 곳에서 폐기하고 새로 받았다

## 4. 올리는 순서

- [ ] 미리보기 주소에서 먼저 확인했다(다른 브랜치나 풀 리퀘스트로 올리면 본 주소와 따로 생긴다)
- [ ] 본 주소로 내보내는 배포 명령은 Claude Code가 늘 묻고 실행하도록 권한을 정해 두었다(`/permissions`)
- [ ] 파일 삭제와 강제 덮어쓰기(강제 푸시 포함)도 늘 묻게 되어 있다
- [ ] 배포 목록에서 새 배포가 "준비됨"으로 바뀌는 것을 봤다

## 5. 열어 보기

- [ ] 내 휴대폰에서 와이파이로 열었다
- [ ] 내 휴대폰에서 휴대폰 데이터로 열었다
- [ ] 동료가 자기 휴대폰으로 도움 없이 열고 입력까지 해 봤다. 동료: [          ]
- [ ] 첫 화면이 보이고, 입력란이 잘리지 않으며, 가로로 밀리는 곳이 없다

## 6. 멈췄을 때를 대비해

- [ ] 잘 돌던 이전 배포로 되돌리는 메뉴(Rollback)가 어디 있는지 확인했다
- [ ] 화면이 그대로일 때 볼 순서를 안다: 브랜치 → 브라우저 캐시 → 배포 로그
- [ ] 노트북과 배포가 다를 때 볼 순서를 안다: 배포 로그 → 환경변수 목록 → 마지막 배포 시각

## 7. 내 도메인을 연결할 때 (선택)

- [ ] 서비스가 알려 준 DNS 값을 캡처해 도메인 관리 담당에게 전달했다. 담당: [          ]
- [ ] 넣은 값과 서비스가 알려 준 값을 한 글자씩 대조했다
- [ ] https로 열리는 것을 확인했다

## 점검 프롬프트 (Claude Code에 붙여 넣기)

```text
이 도구를 배포하기 전에 점검해 줘. 고치지는 말고 먼저 목록으로 보고해 줘.
- 저장소 맨 위에 index.html이 있는지, 첫 화면이 그 파일인지
- 코드와 설정 파일 어디에 인증키, 비밀번호, 실제 회사 이름, 사람 이름, 연락처가 적혀 있는지
- 공개 주소로 올라가면 곤란할 만한 문구나 예시 값이 있는지
- 배포 서비스 설정에서 프레임워크, 빌드 명령, 출력 폴더에 무엇을 넣어야 하는지
문제가 있는 곳은 어떻게 고칠지 계획만 보여 주고, 내가 좋다고 하면 고친 뒤 커밋해 줘.
```
