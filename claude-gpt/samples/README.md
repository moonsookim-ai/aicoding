# 실습 샘플 자료

『클로드 완전정복 100단계』 실습에 쓰는 샘플 자료다. **모두 가상 회사 누리상사(생활용품을 만들어 온라인과
대리점으로 파는 중견 회사)와 가상 지자체 가람시를 두고 꾸며 낸 가공 자료다.** 실제 회사·사람·거래와는
관계가 없고, 숫자도 설명을 돕기 위해 만든 값이다.

회사 자료로 연습하기 전에 이 파일들로 먼저 해 보자. 8단계에서 말한 "올려도 되는 것"에 해당하므로 대화창,
프로젝트, Cowork 작업 폴더, Claude Code 작업 폴더 어디에 넣어도 된다.

## 파일 형식

- CSV 파일은 UTF-8(BOM 포함)로 저장했다. 엑셀에서 더블클릭으로 열어도 한글이 깨지지 않는다.
- 날짜는 `YYYY-MM-DD` 형식이다.
- 금액 단위는 열 이름에 적었다.

## 이 자료를 고쳐 쓸 때

- 우리 회사 자료로 바꿔 넣을 때는 8단계의 자료 구분표와 98단계의 등급표를 먼저 본다.
- 가공한 자료라도 "이 자료만 보고 누구인지, 어느 회사인지 알 수 있는가"를 한 번 더 묻는다.
- 채워 쓰는 양식은 [`../templates/`](../templates/)에 있다.
