# 퀴즈

『클로드·GPT 완전정복 100단계』의 부마다 이해를 확인하는 퀴즈를 모읍니다. 본문의 「스스로 점검」이 방금 읽은 것을
떠올리게 한다면, 퀴즈는 헷갈리기 쉬운 곳과 현장에서 판단이 갈리는 곳을 묻습니다.

## 쓰는 법

- 한 부에 10문항 안팎. 문항마다 관련 단계를 적어, 틀리면 그 단계로 돌아가 읽게 합니다.
- 유형은 네 가지입니다: 고르기(보기 넷), 참·거짓, 짧은 답, 상황 판단(장면을 주고 무엇을 먼저 할지 묻기).
- Claude와 ChatGPT·Codex 어느 쪽으로 공부해도 풀 수 있게 씁니다. 한쪽 도구에만 해당하는 문항은 제목에 도구 이름을 붙입니다.
- 화면 메뉴 이름처럼 자주 바뀌는 것보다 원리와 판단을 묻습니다. 메뉴를 묻는다면 확인한 날을 적습니다.
- 정답과 해설은 접어 두어 먼저 풀어 보게 합니다(아래 양식의 `<details>`).
- 문체는 책과 같이 합쇼체(입니다·합니다)로 씁니다.
