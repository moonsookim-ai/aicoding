# 미션

『클로드·GPT 완전정복 100단계』에서 배운 것을 묶어 한 번에 해 보는 과제를 모읍니다. 단계의 「따라 하기」가
한 가지 기능을 익히는 연습이라면, 미션은 샘플 자료([`../samples/`](../samples/))와 양식([`../templates/`](../templates/))으로
실제 결과물 하나를 끝까지 만들어 보는 일입니다.

## 파일

미션 하나가 파일 하나입니다. 이름은 `m부번호-순번-짧은이름.md`로 붙입니다(예: `m03-1-방문기록-대시보드.md`).

| 부 | 미션 | 상태 |
|---|---|---|
| 제1부~제11부 | 부마다 한두 개 | 준비 중 |

새 미션을 올리면 이 표에 더하고, 저장소의 `CHANGELOG.md`에 적습니다.

## 쓰는 법

- 미션마다 목표, 쓰는 자료, 조건, 제출물, 통과 기준을 적습니다. 통과 기준은 강사용 안내와 같이 우수·통과·보완 세 단계로 씁니다.
- Claude로 해도, ChatGPT·Codex로 해도 끝낼 수 있게 씁니다. 도구마다 순서가 다른 곳은 「Claude로」와 「ChatGPT·Codex로」로 나눠 도움말을 줍니다.
- 샘플 자료에 일부러 넣어 둔 함정(빈 값, 거래처를 알 수 없는 메모, AI를 겨냥한 숨은 지시)을 알아채는지도 기준에 넣습니다.
- 발송·결제·삭제·제출처럼 되돌리기 어려운 일은 미션에서도 사람이 확인하는 단계로 둡니다.
- 문체는 책과 같이 합쇼체(입니다·합니다)로 씁니다.
